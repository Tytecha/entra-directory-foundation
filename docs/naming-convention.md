Northwind Services will name security groups using SEC-<Type>-<Name>. SEC identifies a security group, Type identifies the category, and Name identifies the specific department, role, or location. We will use Dept for departments, Role for job functions or worker categories, and Loc for locations. Examples include SEC-Dept-Finance, SEC-Dept-Sales, and SEC-Role-Helpdesk. This consistent naming convention will make groups easier to find and their purpose easier to understand as the company grows.

Northwind Services will name user accounts using the lowercase user principal name (UPN) pattern firstname.lastname@tholliday1979gmail.onmicrosoft.com. If two users have the same first and last name, we will add a number to the last name, such as maya.carter2@YOURTENANT.onmicrosoft.com. Every person, including contractors, will receive an individual account following this pattern. Consistent account names will help administrators identify users and manage onboarding, troubleshooting, and offboarding.
